# 03 · 디자인 핸드오프

> Claude Design 캔버스 "서브에이전트 타이쿤"의 원본이 `design/canvas/`에 들어 있다. `.dc.html`은 Claude Design 전용 템플릿 형식(HTML + `{{구멍}}` + `<sc-if>/<sc-for>/<dc-import>` + `class Component extends DCLogic`)이라 **그대로 쓰지 않고 SVG와 스타일 값만 뽑아서** React로 옮긴다.
> 브라우저로 바로 열면 템플릿 구멍이 비어 보인다. 모양 확인은 캔버스에서, 값은 파일에서.

## 2. 그림 규칙 (위반하면 다른 손으로 그린 것처럼 보인다)

- 외곽선 `--ink` 3px, 세부선 2px. 끝과 모서리 둥글게 (`stroke-linecap/linejoin: round`).
- 에셋을 배율 s로 줄이거나 키워 넣을 때는 선 굵기를 `3 / s`로 보정. **마을 전체 확대·축소는 보정하지 않는다.**
- 면 음영: 윗면 = 기본, 왼쪽 아래를 향한 면 = `-l`, 오른쪽 아래를 향한 면 = `-r`. 지붕은 왼쪽 경사 = 기본, 오른쪽 경사 = `-l`. 그라데이션 금지. 유리·간판 아이콘·캐릭터는 예외.
- 바닥 그림자: 외곽선 없음, `--ink` 방사형 30% → 0%, 가로:세로 2:1, 빛 반대(오른쪽 아래)로 2~4. 블러 필터 금지.
- 바닥 타일은 외곽선이 없다 (이음새가 안 보이게). 마을 가장자리에만 두께 8 옆면 + 3px 선.
- 에셋 안에 글자 금지.
- 작은 점을 모아 찍지 않는다. 캐릭터 몸 무늬는 큰 점 3개 이하(바탕보다 한 단계만 어둡게), 재질 결(돌, 산호, 나무)은 점 대신 짧은 선. 작은 점 무리는 사람에 따라 강한 거부감을 준다는 피드백이 있었다 (05 문서 5.4).

| 차지 타일 | viewBox | data-anchor | 쓰는 곳 |

### 3.1 건물 (`Building.dc.html`, 모두 2×2)

### 3.3 캐릭터

- 가장 깔끔한 원본은 `Chars.dc.html`의 종별 `<svg>` 4개(곰·토끼·너구리·펭귄). 파츠 `id`와 `data-part`, `data-pivot`이 붙어 있다.
- 외부인(모래색 + 모자)은 `Critter.dc.html`에만 있다.
- 포즈·회전 중심·종별 값은 `design/rig.json`이 정본. 캔버스 코드와 다르면 rig.json을 따른다.
- 표정 층: `data-expr="normal|happy|talk|sleep"` 네 개 중 하나만 보이게.
- 소품 칸: `hold-r`(망치, 쥐는 점 41,−18), `carry`(널빤지).
- 종별 소품: 곰 안경은 `face` 안(시선 따라 움직임), 토끼 베레모·너구리 돋보기·펭귄 나비넥타이는 `body` 안. 붙는 자리 3곳(눈 ±17,−38 / 머리 위 0,−72 / 가슴 0,−12)이 모든 종에 공통이라 소품을 바꿔 씌울 수 있다.
- 프로필 얼굴 = 같은 SVG를 viewBox `-44 -86 88 88`로 자른 것 (`data-face-box`).
- 누르기 포즈 (M16, 06 문서 8장): `flail`(rate 1, 4프레임 — 팔·다리·꼬리 회전 + 몸 ±8° 기울임, 표정 `t`, 프레임 0 = 동작 줄이기의 한 번 기울이기), `held`(flail에 몸·두 발 y −24 → 그림자는 바닥에 남고 `shadowLift`로 작아짐). 파츠 이동·회전만, 크기 변경 없음(`rig.test`). 땀방울은 새 그림이 나오기 전까지 캐릭터 거품(`data-fx="bubbles"`)을 켠다.

### 3.4 아이콘 (`Type.dc.html`)

24 격자, 선 2, 둥근 끝, `--text` 색, 채우지 않음. 코인, 금고, 물가, 알림, 설정, 작업(망치), 회의, 휴식, 막힘, 집, 마을 보기, 격자 보기, 확대, 축소, 전체 보기, 완료, 닫기, 완공, 도서관, 설계사무소, 인력사무소, 가구 상점, 성격, 시간. 간판 전용으로 렌치(공방), 컵(카페), 돋보기+체크(초소), 깃발(회관)이 `Building.dc.html`에 있다.

### 3.5 아직 분리 안 된 그림

- 방 껍데기(벽 2면, 마루, 창문, 액자): `ScreenHouse.dc.html`, `ScreenShop.dc.html` 안의 인라인 SVG. `room.shell` 컴포넌트로 뽑아 6×6 / 3×3 크기를 받게 만든다.
  - M7: `web/src/room/RoomScene.tsx`. 방 단위 = 타일 64×32(배율 1), 바닥 위 꼭짓점이 원점. 캔버스 바다 15(배율 1.6)에서 잰 값: 벽 높이 106.25, 벽 두께 5, 마루 옆면 9, 캐릭터 0.5625(= 0.9 / 1.6). 둥근 창은 오른쪽 벽, 액자는 왼쪽 벽의 같은 비율 자리 — 크기 `size`가 바뀌어도 벽 위에 남는다. 색은 토큰: 벽 `--nacre-r`(왼쪽)·`--nacre-l`(오른쪽)·`--nacre-top`(윗면)·`--cap-edge`(두께), 마루 `--wreck-*`, 창 테 `--brass-l/-r`, 창 유리 `--water-bg-2`, 물고기 `--fish-school`, 광택 줄 `--nacre-sheen-1`.

## 4. 추출 방법 (`tools/extract-assets.ts`)

1. `design/canvas/*.dc.html`을 HTML 파서로 읽고 `data-asset-id`가 붙은 `<svg>`를 모두 찾는다. 같은 id가 여러 번 나오면 `Building.dc.html` / `Prop.dc.html` / `Chars.dc.html` 쪽을 우선.
2. 감싼 `<sc-if>`, `<sc-for>`, 위치용 `style="position: absolute…"`는 버린다.
3. 구멍 치환
   - 색 `{{roof}}` 등 → 컴포넌트 props (`colors.roof`). SVG 속성 안의 `var()`는 브라우저마다 다르게 동작하므로 **props로 넣거나 `style={{ fill: 'var(--roof)' }}`** 로.
   - 선 `stroke-width="{{w3}}"` → `strokeWidth={3 * k}` (`k = 1 / 배율`)
   - 반지름 `r="{{rT20}}"` → `r={20 + 3 * k}`
   - `transform="{{t.armL}}"`, `display="{{e.n}}"` → 리그 런타임이 채움 (02 문서 7.4)
   - `top: {{roofY}}px` → 조립기가 `translate(0, -wallHeight)`
4. `class="s"` 같은 클래스 스타일은 해당 파일 `<helmet><style>`에서 값을 읽어 속성으로 풀어 쓴다 (`.s` = stroke `#7a3e3e`, width 3, round).
5. `data-*` 속성은 모두 유지한다 (`data-asset-id`, `data-anchor`, `data-tiles`, `data-pivot`, `data-part`, `data-wall-height`, `data-reveal`, `data-layer`).
6. 결과를 `packages/web/assets/land/<group>/<id>.tsx`로 쓰고 (바다 테마는 `assets/sea/`, 05 문서 8장), 갤러리 페이지(`/dev/gallery`)에서 캔버스 09~11 보드와 같은 배열로 보여 준다. 캔버스와 눈으로 비교해 통과시킨다.

## 7. 동물 추가 (요약, 자세한 건 `Guide.dc.html`)

1. 바꾸지 않는 것: 몸통 path, 파츠 id, 회전 중심, 팔·눈·코 좌표, viewBox, 포즈 표.
2. 바꾸는 것: 털색 3~4개(토큰 추가), 귀 모양과 귀 회전 중심, 얼굴 무늬(점은 큰 것 3개 이하, 2장), 꼬리(있으면), `earGain`.
3. `design/rig.json`의 `species`에 한 줄 추가 (예시: `exampleFox`).
4. 7포즈 전부 돌려 보고 확인: 귀·꼬리가 viewBox 위(−126) 안, 망치·널빤지가 손에 맞음, 프로필 영역에 얼굴이 다 들어옴, 0.45배에서 실루엣으로 구분됨.
5. 몸통이나 눈 위치가 다른 동물(기린, 뱀, 긴 부리 새, 개구리)은 공통 리그를 못 쓴다.
6. 바다 동물은 `design/rig.sea.json`에 넣는다 (05 문서 6.5). 2026-09-30부터 부품 라이브러리(`{{pt.부품}}`)가 있어서, 있는 부품으로 되는 동물은 그림 없이 species 한 줄(부품 목록 + 색)이면 된다 (D15). 새 동물 색은 `tokens-sea.css`에 종 이름 접두어 토큰으로 (`--gentoo-fur` 등) — 이유: 동물마다 털색이 달라 공용 토큰으로 못 쓴다. 자동 변형용 염색 8색은 `--dye-<이름>`(털)·`--dye-<이름>-d`(팔·무늬) (D16) — 이유: 도감보다 팀원이 많을 때 같은 동물을 색으로 가르기 위해.
