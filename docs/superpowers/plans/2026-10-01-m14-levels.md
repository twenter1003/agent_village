# M14 마을 레벨·공공시설 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 마을이 Lv.1~10으로 자란다. 하루 정산에서 마을 전체 일 점수(팀원 일터 점수 합)가 다음 레벨 기준을 넘고 기금으로 공사비를 낼 수 있으면 레벨업한다. 레벨업하면 섬이 넓어지고 일터 3층·큰 건물이 열린다. 시청(팀장 건물)은 1층 → 2층 → 3층 → 해저 궁전으로 자라고, 기금으로 공공시설(가로등·벤치·꽃밭·공원·길 포장·랜드마크)을 하루에 하나 짓는다 (06 문서 6장, D24). 완료 기준(16장): 성장 시뮬레이션이 6.1 속도 가늠 안에 들고, 팀원 1명 마을도 Lv.10까지 간다.

**Architecture:** 새 규칙 파일 `packages/core/src/rules/village.ts`(레벨업·공공시설·시청 층)를 `economy.ts`의 `settle`에 두 군데 붙인다. 정산 순서는 **레벨업 → 일터 층(`raiseAll`) → 자동 구매 → 공공시설 하나 → 기록**이다. 시청 자리는 마을을 세울 때(`growth.ts` `found`) 잡는다. 공공시설 자리는 규칙이 정한다: 소품 칸은 `layout/lots.ts`, 3×3은 `findLot`을 쓴다. 상태에는 `VillageState.hall`·`publicWorks`, `today.works`·`DayRecord.works`를 더하고 옛 `economy.plaza`는 뺀다. 웹에서는 `sceneFromState`가 시청·랜드마크·공원·소품·길 포장을 장면으로 만든다(임시 그림). 상단 바 "마을 공사" 칸은 레벨 칸으로 바뀌고, 경제 패널 기금 흐름에는 "레벨업·공공시설" 줄이 생긴다. 알림 글자는 이름 사전에서 꺼낸다(`noticeText`).

**Tech Stack:** TypeScript (strict, noUncheckedIndexedAccess), pnpm workspace, Vitest (+ happy-dom), React SVG, Playwright, `node:sqlite`(재생), tsx.

**Spec:** `docs/06-도시와-경제.md` 6장(6.1~6.3), 3.3(기금 흐름), 4장(팀장 = 시장), 5.4·5.9(레벨 게이트·M13 메모), 12장(배치), 13장(화면), 14장(임시 그림), 15장(설정값), 16장(완료 기준). 프로젝트 규칙 `CLAUDE.md`. 이어 붙일 곳 `docs/HANDOFF.md` 3장.

## Global Constraints

- 스펙은 `docs/06-도시와-경제.md` 6장이다. 다르게 가야 하면 코드보다 06 문서를 먼저 고친다 (CLAUDE.md). Task 1이 위 결정을 6.4에 적는다.

- **공공시설 표 `publicWorks`** (06 문서 6.2): 가로등 `streetlamp` 100 · Lv.1 · 길가, 벤치 `bench` 100 · Lv.1 · 광장 둘레, 꽃밭 `flowers` 100 · Lv.1 · 광장 둘레, 공원 `park` 400 · Lv.4 · 빈 3×3, 길 포장 `paving` 600 · Lv.4 · 십자 길 전체(한 번), 등대 `landmark` 2,000 · Lv.7 · 광장 옆 3×3. 두 번째 랜드마크 `landmark2`는 표에 없다. Lv.10 레벨업 때 값 0으로, 첫 랜드마크 반대 구역의 3×3에 생긴다. 가로등·벤치·꽃밭은 자리가 남는 동안 되풀이한다.
- 일터 층 표(`workplace.levels`, 5.3)는 그대로 둔다: 0·75·225·450점, 레벨 1·1·4·7, 자재비 0·800·1,200·1,700.
- **하루 정산 순서**: 레벨업(`levelUp`) → 일터 층(`raiseAll`) → 자동 구매 → 공공시설 하나(`buildPublicWork`) → 기록(`DayRecord`) → `today` 비우기. 레벨업은 정산에서만 일어난다(실행이 끝날 때는 일어나지 않음).
- 마을 전체 일 점수 = `villagePoints(s)` = 팀원 일터 점수 합. 레벨은 내려가지 않는다. 시청·공공시설·일터는 지우지 않는다.
- 진주 불변식: 팀원 잔고 + 기금 + 가구(낸 값) + 낸 토큰(팀원·팀장) + 자재비 + 레벨업·공공시설(`Σ works`) = 받은 급여.
- 알림 ref: 레벨업 `@level:<n>:<시대>`, 공공시설 `@work:<종류>:<값>`. 상태 글자는 테마가 없다("마을 레벨 Lv.4", "마을 기금으로 공공시설을 지었어요 · 400", "레벨업으로 공공시설이 생겼어요").
- 프로젝터는 순수다: `Date.now()`·`Math.random()` 금지, 시각은 이벤트, id는 결정적(`<종류>`·`<종류>:<n>`, 토스트는 `nextId`).
- 상태에는 정본 id만 둔다(시대 `village|town|city|capital`, 공공시설 종류). 화면 글자는 이름 사전(`theme-map.sea.json` labels + `packages/web/src/i18n.ts`)에서 꺼낸다. 색·선·글꼴은 토큰만 쓰고 새 토큰은 없다. 배율 s로 넣는 에셋은 선 `3 / s`(있는 `Building`·`OwnerSign` 그대로).
- 웹 테스트 공통 마을 `packages/web/src/test/village.ts` `fullVillage`는 `hall = null`, `publicWorks = []`로 비운다. M3~M9 기준 배치를 그대로 두려는 것이다. 시청·공공시설 테스트는 직접 넣는다.
- Task 2부터 Task 7 끝까지 `pnpm lint`(tsc -b)는 웹·서버 컴파일 오류로 빨간 게 정상이다. 태스크마다 자기 범위만 초록으로 만든다(`pnpm vitest run <경로>`, `pnpm exec tsc -b packages/core`). **Task 7 끝에서 `pnpm lint`·`pnpm test`가 전부 초록**이어야 한다. 골든(`replay.test.ts`)은 Task 5에서 한 번만 다시 만든다.
- 저장소에서 `pnpm dev`를 켜지 않는다. `~/.subagent-tycoon/app`(보는 용 복사본)과 실제 DB는 건드리지 않는다. 재생은 `~/.subagent-tycoon/tycoon.db*`를 임시 폴더에 복사해 `TYCOON_DB=<복사본>`으로 한다. e2e는 4798·5174.

```ts
/** 마을 시대 (06 문서 6.1): 정본 id. 바다 이름은 theme-map labels.eras */
export const ERAS = ['village', 'town', 'city', 'capital'] as const;
export type Era = (typeof ERAS)[number];

/** 마을 레벨 표·공공시설 표도 손으로 고친 값을 믿지 않는다 (06 문서 6장): 숫자가 아니면 레벨이 영영 안 오르고, 값이 음수면
 *  기금이 생기고, 점수가 줄면 레벨을 건너뛰고, 모르는 시대면 시청 층을 모른다 → 기본 표로. 빈 공공시설 표는 받는다 */
function saneVillage(c: GameConfig): GameConfig {
  const obj = (v: unknown): v is Record<string, unknown> => typeof v === 'object' && v !== null;
  const num = (v: unknown, min: number) => typeof v === 'number' && Number.isFinite(v) && v >= min;
  const v: unknown = c.village;
  const levels = obj(v) ? v.levels : undefined;
  const okLevels =
    Array.isArray(levels) &&
    levels.length >= 1 &&
    levels.every(
      (l: unknown, i) =>
        obj(l) &&
        num(l.points, 0) &&
        num(l.cost, 0) &&
        (ERAS as readonly unknown[]).includes(l.era) &&
        (i === 0 || (l.points as number) >= (levels[i - 1] as { points: number }).points),
    );
  const works: unknown = c.publicWorks;
  const okWorks =
    Array.isArray(works) &&
    works.every((w: unknown) => obj(w) && typeof w.id === 'string' && num(w.cost, 0) && num(w.level, 1));
  if (okLevels && okWorks) return c;
  return {
    ...c,
    village: okLevels ? c.village : { ...(obj(v) ? v : {}), levels: defaults.village.levels },
    publicWorks: okWorks ? c.publicWorks : defaults.publicWorks,
  } as GameConfig;
}

export const makeConfig = (t?: TycoonConfig): GameConfig =>
  saneVillage(saneWorkplace(saneTime(deepMerge(defaults, t?.overrides ?? {}))));
```

```ts
// 마을 레벨·공공시설·시청 (06 문서 6장, D24, 6.4 구현 메모). 하루 정산(economy settle)이 부른다:
// 레벨업 → 일터 층 → 자동 구매 → 공공시설 하나. 순수: 시각은 이벤트, id는 종류·순번
import { ERAS, type Era, type GameConfig } from '../config/config';
import { nextId } from '../projector/project';
import type { VillageState } from '../projector/types';

/** 마을 전체 일 점수 (6.1) = 팀원 일터 점수 합. 팀원 몫만(외부인·팀장은 일터에 안 쌓인다, 5.2), 내려가지 않는다 */
export const villagePoints = (s: VillageState) =>
  Math.round(Object.values(s.buildings).reduce((a, b) => a + b.points, 0) * 1e6) / 1e6;

/** 지금 레벨 줄·다음 레벨 줄(최고면 null)·점수·기금 (상단 바 레벨 칸, 06 문서 13장) */
export function levelOf(s: VillageState, cfg: GameConfig) {
  const rows = cfg.village.levels;
  const cur = rows[Math.min(s.level, rows.length) - 1] ?? { points: 0, cost: 0, era: 'village' };
  return {
    level: s.level,
    era: cur.era as Era,
    cur,
    next: rows[s.level] ?? null,
    points: villagePoints(s),
    fund: s.economy.fund,
  };
}

/** 시청 층 (6.3) = 시대 순서: 모래섬 마을 1 · 읍 2 · 도시 3 · 수도 4(해저 궁전, 3×3) */
export const hallFloor = (s: VillageState, cfg: GameConfig) => ERAS.indexOf(levelOf(s, cfg).era) + 1;

/** 레벨업 (6.1·6.4): 마을 전체 일 점수 ≥ 다음 레벨 점수이고 기금 ≥ 공사비면 공사비를 내고 +1. 여러 레벨도 차례로(레벨마다 공사비·알림).
 *  레벨마다 섬 사방 4칸(maxRing까지), 입주한 팀원(팀장 포함) 모두 환호. 글자는 테마 없이 — 화면이 ref로 이름 사전에서 */
export function levelUp(s: VillageState, day: number, at: number, cfg: GameConfig): void {
  const points = villagePoints(s);
  const ec = s.economy;
  for (;;) {
    const next = cfg.village.levels[s.level];
    if (!next || points < next.points || ec.fund < next.cost) return;
    ec.fund -= next.cost;
```

```ts
const SMALL = new Set<string>(['streetlamp', 'bench', 'flowers']);
const KINDS = new Set<string>([...SMALL, 'park', 'paving', 'landmark']);
const OPPOSITE: Record<Zone, Zone> = { north: 'south', south: 'north', east: 'west', west: 'east' };

/** 여러 구역 중 광장에 가장 가까운 빈 3×3 (6.2 공원·랜드마크). 모자라면 섬을 넓혀 다시, maxRing까지 없으면 null */
function placeNear(s: VillageState, zones: Zone[], cfg: GameConfig): Lot | null {
  const d = (l: Lot) => Math.hypot(l.x + 1.5 - MAP / 2, l.y + 1.5 - MAP / 2);
  for (;;) {
    const occupied = occupiedLots(s);
    const best = zones
      .flatMap((z) => findLot(z, occupied, s.ring, 3) ?? [])
      .sort((a, b) => d(a) - d(b) || a.y - b.y || a.x - b.x)[0];
    if (best) return best;
    if (s.ring >= cfg.layout.maxRing) return null;
    s.ring++;
  }
}

/** 자리 (6.4): 소품 = 비어 있는 첫 칸(가로등 길가, 벤치·꽃밭 광장 둘레), 공원·랜드마크 = 광장에 가장 가까운 빈 3×3,
 *  두 번째 랜드마크 = 첫 랜드마크 반대 구역, 길 포장 = 자리 없음. 둘 데가 없으면 undefined — 사지 않는다 (3.2 규칙 4) */
function placeFor(s: VillageState, kind: WorkKind, cfg: GameConfig): Pick<PublicWork, 'spot' | 'lot'> | undefined {
  if (kind === 'paving') return { spot: null, lot: null };
  if (SMALL.has(kind)) {
    const taken = new Set(s.publicWorks.flatMap((w) => (w.spot ? [`${w.spot.x},${w.spot.y}`] : [])));
    const xy = (kind === 'streetlamp' ? roadsideSpots(s.ring) : PLAZA_RIM).find(([x, y]) => !taken.has(`${x},${y}`));
    return xy && { spot: { x: xy[0], y: xy[1] }, lot: null };
  }
  const first = s.publicWorks.find((w) => w.kind === 'landmark')?.lot;
  const zones: Zone[] =
    kind === 'landmark2' && first ? [OPPOSITE[zoneOf(first)]] : ['north', 'east', 'south', 'west'];
  const lot = placeNear(s, zones, cfg);
  return lot ? { spot: null, lot } : undefined;
}

/** 짓기: 기금에서 값을 내고 기록·알림 (6.4: 한 번짜리는 토스트도, 소품은 활동 기록만). 자리가 없으면 false */
function build(s: VillageState, kind: WorkKind, cost: number, day: number, at: number, cfg: GameConfig): boolean {
  const place = placeFor(s, kind, cfg);
  if (!place) return false;
  const n = s.publicWorks.filter((w) => w.kind === kind).length + 1;
  s.publicWorks.push({ id: SMALL.has(kind) ? `${kind}:${n}` : kind, kind, day, cost, ...place });
  s.economy.fund -= cost;
  s.economy.today.works += cost;
  const text = cost ? `마을 기금으로 공공시설을 지었어요 · ${cost}` : '레벨업으로 공공시설이 생겼어요';
  const ref = `@work:${kind}:${cost}`;
  s.feed.push({ at, kind: 'economy', text, ref });
  if (!SMALL.has(kind)) s.toasts.push({ id: nextId(s, 'toast'), at, kind: 'complete', text, sticky: false, ref });
  return true;
}

/** 공공시설 하나 (6.2·6.4). 다음 레벨 점수가 찼으면(레벨업 공사비 대기) 모은다. 열린 한 번짜리를 목록 순서로 먼저 짓고,
 *  그다음 소품을 가로등 → 벤치 → 꽃밭 차례로(자리 없는 종류는 건너뜀). 차례인 것의 값이 남는 기금
 *  (= 기금 − 오늘 팀장 토큰값 청구)보다 크면 모은다 */
export function buildPublicWork(s: VillageState, day: number, at: number, cfg: GameConfig): void {
  const next = cfg.village.levels[s.level];
  if (next && villagePoints(s) >= next.points) return;
  const ec = s.economy;
  const spare = ec.fund - ec.today.leaderTokens - ec.today.leaderUnpaid;
  const open = cfg.publicWorks.filter((r) => r.level <= s.level && KINDS.has(r.id));
  const once = open.filter((r) => !SMALL.has(r.id) && !s.publicWorks.some((w) => w.kind === r.id));
  const small = open.filter((r) => SMALL.has(r.id));
  const k = s.publicWorks.filter((w) => SMALL.has(w.kind)).length;
  for (const r of [...once, ...small.map((_, i) => small[(k + i) % small.length])]) {
    if (!r) continue;
    if (r.cost > spare) return;
    if (build(s, r.id as WorkKind, r.cost, day, at, cfg)) return;
  }
}
```
