# M12 경제 정리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 진주를 "토큰값을 했는가"로 바꾼다 — 급여 = 도구 호출 수 × 16 × 품질, 진주 1 = 비용 환산 토큰 1,000, 물가·중앙은행·관리비·입주 지원금·완공 보너스·효율 급여 보정 제거, 팀장 = 시장(지갑 = 마을 기금), 효율 순위 = 일 점수 1점당 토큰.

**Architecture:** 규칙은 `packages/core/src/rules/economy.ts` 한 곳(순수 함수, 이벤트 시각·seed만). 상태 모양은 `projector/types.ts`, 기본 수치는 `design/game.default.json`(GameConfig 타입이 여기서 나옴). 수집기(`packages/server`)는 경제 API 모양만, 웹(`packages/web`)은 경제 패널·상단 바·집·상점·토스트 화면만 따라 바꾼다. 원본 이벤트는 그대로 — 새 규칙으로 재생하면 모든 마을이 다시 계산된다.

**Tech Stack:** TypeScript, pnpm workspace, vitest, React (web), node:sqlite (server), Playwright (e2e).

**Spec:** `docs/06-도시와-경제.md` 3·4장 (결정 D20·D21·D23), 16장 M12 완료 기준. 프로젝트 규칙 `CLAUDE.md`.

## Global Constraints

- 프로젝터·규칙은 순수 함수: `Date.now()`·`Math.random()` 금지. 난수는 seed 해시(`rand(n, k)`)만.
- 금액은 모두 정수 (진주). 빚 없음 — 모자라면 가진 만큼 내고 0에서 멈춤.
- 상태에는 정본(잔디) id만, 화면 글자는 이름 사전(`packages/web/src/i18n.ts`)에서. 화폐 단위 글자를 상태·feed 글에 넣지 않는다.
- 색·선·글꼴은 `design/tokens.css` 토큰만.
- 원본 이벤트(`raw_events`)는 지우지 않는다. 테스트는 실제 `~/.subagent-tycoon`·`~/.claude`를 건드리지 않는다.
- 새 수치: `economy.wagePerCall` = 16, `economy.taxRate` = 0.2, `economy.tokens.perPearl` = 1000, `economy.autoBuy.seed` = 42.
- 뺄 설정 키 (M12 범위): `economy.startBalance`, `economy.baseSalary`, `economy.difficulty`, `economy.buildingBonusPerTask`, `economy.houseUpkeepPerDay`, `economy.furnitureUpkeepPerDay`, `economy.priceIndex`, `economy.centralBank`, `efficiency.salary`. **`economy.plaza`는 M14(공공시설)까지 둔다.** `buildings.*`는 M13까지 둔다.
- 끝날 때 `pnpm test`, `pnpm lint`, `pnpm e2e` 모두 통과. 이 저장소는 git이 아니다 — 커밋 단계 없음, 대신 `docs/04-작업계획.md` 체크와 작업 기록 한 줄.

/** 6.4 가구 가격 = basePrice (고정, D20 규칙 2 — 물가 없음). 모르는 가구는 null */
export function furniturePrice(kind: string, cfg: GameConfig): number | null {
  return cfg.furniture.find((x) => x.id === kind)?.basePrice ?? null;
}

/** 일 점수 (06 문서 5.2) = 도구 호출 수 × 품질. 급여·효율·(M13) 일터 게이지의 공통 단위 */
export function workPoints(t: Pick<Task, 'toolCalls' | 'quality'>, cfg: GameConfig): number {
  return t.toolCalls * cfg.economy.quality[t.quality];
}

/** 6.1 급여(세전, 반올림 정수) = wagePerCall × 도구 호출 수 × 품질 (D20). 쪼개도 합이 같다 */
export function salary(toolCalls: number, quality: Task['quality'], cfg: GameConfig): number {
  return Math.max(0, Math.round(cfg.economy.wagePerCall * workPoints({ toolCalls, quality }, cfg)));
}
```

/** 효율 순위 (D23, 06 문서 3.6): 입주한 팀원(팀장·떠난 팀원 뺌)의 최근 window건 토큰 ÷ 일 점수, 적은 순.
 *  rank null = 순위 밖 (few: minTasks건 미만, noTokens: 토큰을 못 읽음). 일 점수가 0(실패만)이면 perPoint Infinity로 꼴찌.
 *  team = 마을 전체(팀장·외부인 포함) 지금까지 토큰 ÷ 끝낸 작업의 일 점수 합 */
export function efficiency(s: VillageState, cfg: GameConfig) {
  const rows = Object.values(s.members)
    .filter((m) => !m.isLeader && !m.departed && m.movedInAt !== null)
    .map((m) => {
      const tokens = m.eff.recent.reduce((a, x) => a + x.tokens, m.eff.pending);
      const points = m.eff.recent.reduce((a, x) => a + x.credit, 0);
      const tasks = m.eff.recent.length;
      const why = tasks < cfg.efficiency.minTasks ? 'few' : tokens <= 0 ? 'noTokens' : null;
      return { m, tasks, tokens, perPoint: points > 0 ? tokens / points : Infinity, why, rank: null as number | null };
    })
    .sort((a, b) => Number(!!a.why) - Number(!!b.why) || (a.why ? 0 : a.perPoint - b.perPoint) || a.m.slot - b.m.slot);
  rows.forEach((r, i) => (r.rank = r.why ? null : i + 1));
  const visitors = Object.values(s.runs).reduce((a, r) => a + (r.memberId ? 0 : (r.tokens ?? 0)), 0);
  const tokens = Object.values(s.members).reduce((a, m) => a + m.tokens, visitors);
  const points = Object.values(s.tasks)
    .filter((t) => t.status === 'completed')
    .reduce((a, t) => a + workPoints(t, cfg), 0);
  const leader = s.members[LEADER_ID]?.tokens ?? 0;
  return {
    rows,
    ranked: rows.filter((r) => r.rank !== null).length,
    team: { tokens, points, perPoint: points ? tokens / points : null, leaderShare: tokens ? leader / tokens : 0 },
  };
}
```
