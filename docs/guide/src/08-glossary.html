8장. 용어 설명

이 장은 타이쿤에서 쓰는 말을 가나다순으로 모은 사전입니다. 화면에 보이는 이름, 게임 규칙에 나오는 말, 설정과 명령에 나오는 말을 모두 담았습니다.

  • 표의 뜻은 그 말이 타이쿤에서 무엇을 가리키는지입니다. 숫자는 모두 기본값입니다. 마을 설정에서 바꾼 값은 앱 안 설명서(상단 바 "?")에 지금 값으로 나옵니다.

  • "→" 표시는 같은 것을 가리키는 다른 이름입니다. 화살표가 가리키는 용어에 뜻이 있습니다.
  • 서브에이전트, 훅, 토큰, 캐시처럼 Claude Code 자체의 말은 장 끝 「Claude Code 용어」에 따로 모았습니다.
  • 자세한 규칙은 게임 규칙 장, 화면 배치는 화면 구성 장, 쓰는 법은 기능 설명 장에 있습니다.
